# Gather public website

Gather’s public marketing website, separate from the authenticated application. The approved launch rebuild uses Next.js 16.3.3, React 19.2.8 and TypeScript, retaining the verified live baseline’s framework versions.

## Run and check

```sh
npm ci
npm run build
npm run start -- --hostname 127.0.0.1 --port 3001
npm run lint
npm run typecheck
npm test
npm run test:capture
```

Browser tests use Chromium, Firefox and Playwright WebKit. Install their runtimes with `npx playwright install chromium firefox webkit` if not already available. Tests expect the local production server on port 3001; `PLAYWRIGHT_BASE_URL` can select another local review origin. They never submit signup forms, send email, or change the app. Local evidence is saved under gitignored `artifacts/launch`.

## Where to make updates

- Page copy: `src/app/page.tsx`, `how-it-works/page.tsx`, `get-involved/page.tsx`, `impact/page.tsx`, `about/page.tsx`.
- Shared destinations and canonical domain: `src/lib/site-config.ts`.
- Launch popup enabled state, campaign identifier and delay: `src/lib/launch-campaign.ts`. With `npm run dev`, run `window.resetGatherLaunch()` in the browser console to reset the campaign. No public reset control ships in production.
- Public impact totals: `src/lib/impact.ts`. Currently intentionally unavailable. Connect only an approved aggregate adapter returning `foodRescuedLb`, `rescuesCompleted`, `volunteerHours`. Null and failures display `--`; measured zero displays `0`. No database, volunteer records, or service keys are present.
- Visual tokens and page layouts: `src/app/globals.css`; navigation/dialog/disclosure styles: `src/components/interactions.css`.
- Mark derivative: `public/brand/gather-mark.png`; original-derived app icons and share graphic generated by `scripts/prepare-brand.mjs`.
- Photography provenance and exact generation prompts: `docs/LAUNCH-ASSETS.md`. Scenes are illustrative, not documented Gather events or people.
- Approved visual authority and motion plan: `DESIGN-BLUEPRINT.md`, `docs/approved-launch-design.png`, `docs/APPROVED-REBUILD-BRIEF.md`.
