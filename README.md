# Gather public website

Gather’s public marketing website, separate from the authenticated application. The approved launch rebuild uses Next.js 16.3.3, React 19.2.8 and TypeScript, retaining the verified live baseline’s framework versions.

## Run and check

```sh
npm ci
npm run build
npm run start -- --hostname 127.0.0.1 --port 3001
npm run lint
npm run typecheck
npm test
npm run test:capture
```

Browser tests use Chromium, Firefox and Playwright WebKit. Install their runtimes with `npx playwright install chromium firefox webkit` if not already available. Tests expect the local production server on port 3001; `PLAYWRIGHT_BASE_URL` can select another local review origin. Build with `VERCEL_ENV=preview` and test with `PLAYWRIGHT_PREVIEW_RESET=true` to exercise the protected-preview reset. Tests never submit signup forms, send email, or change the app. Current local evidence is saved under gitignored `artifacts/finishing`; the first build’s evidence remains in `artifacts/launch`.

## Where to make updates

- Page copy: `src/app/page.tsx`, `how-it-works/page.tsx`, `get-involved/page.tsx`, `impact/page.tsx`, `about/page.tsx`.
- Shared destinations and canonical domain: `src/lib/site-config.ts`.
- Launch popup enabled state, campaign identifier and delay: `src/lib/launch-campaign.ts`. In development or the Vercel Preview, run `window.resetGatherLaunch()` in the browser console to reset only this campaign. No public reset control or console hook ships in Production. Only intentional dismissal is persisted; see `docs/POPUP-DIAGNOSIS.md`.
- Public impact totals: `src/lib/impact.ts`. Currently intentionally unavailable. Connect only an approved aggregate adapter returning `foodRescuedLb`, `rescuesCompleted`, `volunteerHours`. Null and failures display `--`; measured zero displays `0`. No database, volunteer records, or service keys are present.
- Visual tokens and base page layouts: `src/app/globals.css`; richer responsive compositions: `src/app/finishing.css`; navigation/dialog/disclosure styles: `src/components/interactions.css`. Custom SVGs and the illustrated rescue route live in `src/components/gather-graphics.tsx` with scoped CSS.
- Mark derivative: `public/brand/gather-mark.png`; original-derived app icons and share graphic generated by `scripts/prepare-brand.mjs`.
- Photography: `docs/FINISHING-ASSETS.md` records eight newly licensed stock photos; `docs/LAUNCH-ASSETS.md` records original generated images. The Home hero and Impact background retain two generated images. All scenes are illustrative, not documented Gather events or people.
- Approved visual authority and motion plan: `DESIGN-BLUEPRINT.md`, `docs/approved-launch-design.png`, `docs/APPROVED-REBUILD-BRIEF.md`, `docs/FINISHING-BRIEF.md`, `docs/FINISHING-PLAN.md`.
